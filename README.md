# AWS Hackathon for Mandai Wildlife Group (Team 7)

Guest Data and Interpretives Study Results : https://drive.google.com/file/d/1dod3GOczgv_BxictYbQ3uNPjULkPjQTf/view

**Challenge Statement:**

How might you use KIRO to create a personalised, AI_powered experience at a zoo exhibit that helps guests connect more deeply with animals and inspire greater appreciation for wildlife and nature

**Brainstorming of solutions**
- mobile app (can be integrated into the current Mandai app) which serves as an audio guide to visitors, including those with visual impairment
- visitors can tailor the complexity of their audio guide based on their age.
- visitors can scan animals and attain badges upon scanning some animals
